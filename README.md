#Python Learning Repository

This repository contains Python learning materials and practice exercises, organized from beginner fundamentals through lists and sequences, with a separate FreeCodeCamp workshop area.

## Overview

The codebase is structured as a learning path covering:

- Python fundamentals
- Lists
- Lists and sequences
- Object-oriented programming examples
- FreeCodeCamp workshop exercises and lab sessions

## Repository Layout

- `nannoy_be/` — core Python learning files
- `nannoy_be/freecodecamp_workshop/` — FreeCodeCamp lab sessions and workshop exercises
